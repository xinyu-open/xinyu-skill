# topic delete（删除主题）

删除一条主题，**不可恢复**。

> [!CAUTION]
> 删除后主题及其评论不再可见且无法还原。执行前必须：
> 1. 用 `topic detail` 展示该主题的标题/摘要与作者，让用户确认是目标主题
> 2. 明确告知不可恢复，得到用户明确同意
> 3. 命令必须带 `--yes`，否则拒绝执行

## 命令

```bash
xinyu-cli topic delete --topic-id 111222333 --yes
```

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `--topic-id <id>` | **是** | 主题 ID |
| `--yes` | **是** | 确认删除（缺少时命令直接拒绝） |

## 输出

`✓ 主题已删除：111222333`

## 推荐工作流

1. `xinyu-cli topic detail --topic-id <id>` 核对主题
2. 向用户复述「将删除主题《标题》（作者、发布时间）」，得到确认
3. 执行 `topic delete --topic-id <id> --yes`

## 失败语义

删除失败时主题保持不变，不会出现部分删除。

## 错误说明

| 错误 | 原因 |
|------|------|
| `删除主题 属于不可恢复操作，确认后请追加 --yes` | 缺少 `--yes` |
| `无权限操作 [code 112]` | 不是作者且无管理权限 |
| `主题不存在` | `topic_id` 无效或已删除 |

通用错误见 [auth-errors](auth-errors.md#常见错误处理)。
